# Electricity Bill Management System (Java Swing)

## 📌 Overview
This is a basic desktop application developed using Java Swing to understand GUI development, object-oriented programming, and application structure. The project demonstrates how different modules interact in a simple Java application.

## 🚀 Features
- Add Customer details (Name, Meter No, Address)
- View Customers in tabular format
- Generate Bill based on electricity units
- Simple billing calculation logic

## 🛠 Tech Stack
- Java
- Swing (GUI)

## 🎯 Purpose
This project was built as a learning exercise to strengthen my understanding of Java, OOP concepts, and GUI-based application development.

## 🧩 Project Structure
- `Main.java` – Entry point of the application  
- `ElectricityGUI.java` – Main UI layout  
- `AddCustomer.java` – Add customer functionality  
- `ViewCustomers.java` – Display customer data  
- `GenerateBill.java` – Bill calculation and generation
