# Electricity Bill Management System (Java Swing)

## 📌 Overview
This is a basic desktop application developed using Java Swing to understand GUI development, object-oriented programming, and application structure.

## 🚀 Features
- Add Customer
- View Customers
- Generate Bill
- Simple billing calculation based on units

## 🛠 Tech Stack
- Java
- Swing (GUI)

## 🎯 Purpose
This project was built as a learning exercise to strengthen my understanding of Java, OOP concepts, and GUI-based application development.
